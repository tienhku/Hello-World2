# Project memory

This repository is used as the working directory for Claude sessions that help with
the monthly paperwork of the 健康台灣深耕計畫 (Healthy Taiwan Deep Cultivation Program).
The real documents live in the user's Google Drive, not in this repo.

**This repo is public. Never commit personal data here** (names, employee IDs, schedules,
leave dates, patient data, Drive file IDs). Keep all of that in Drive.

## Start here

Before doing any 工作日誌 (monthly timesheet) work, read the Google Doc
**「工作日誌製作流程與紀錄（Claude）」** in Drive folder
`__AI_CCH\工作&SOP\外部計畫\健康台灣深耕計畫\`. It holds the full SOP, the rules for
picking dates, the per-month status table and the open to-do items. Update that doc
(not this file) when the process or status changes.

## Key rules (summary)

- File name month = the month the work was done (`..._115MM.doc`), always `.doc` format.
- 5 entries × 2 h per month, weekdays only; check the 麻醉部正式班表 in `__CCH\ban`:
  the `C. K.` column means leave (do not use that day); days not on the schedule count as
  AI-center work days; ad-hoc leave is not on the schedule, so ask the user.
- Vary the wording each month.
- Drive cannot overwrite file content: trash the old file first, then upload the new one,
  otherwise the desktop sync client creates "(1)" duplicates.
